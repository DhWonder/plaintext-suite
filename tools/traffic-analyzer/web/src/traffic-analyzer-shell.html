Live capture is not available when this page is opened from a file. Why, and how to get it
A browser is not allowed to read packets off a network card, so watching traffic as it happens needs the Python side running on the machine you want to watch: python3 flood_watch.py watch then open http://127.0.0.1:8724. It serves this exact page, plus a live capture button and a list of every capture you have saved. Everything else here, reading capture files of any size, works right now with nothing running.
Reading this capture on the page thread. This browser would not let a background thread read a file from a page opened straight off the disk, which is a Safari rule rather than anything wrong with the capture. Everything works the same. A very large capture will just make the page sit still while it reads, instead of staying smooth.

Every address that sent something

Search, sort, filter, then click a row. Scroll to the bottom to load more. This lists addresses that sent traffic, because that is what an attacker does. A machine on your network that only received is counted in the totals but has no row here, so a quiet device can be present in the capture and absent from this list. On a switched network a card also only sees its own traffic unless there is a mirror port, so other machines may not appear at all.

Where the traffic came from

Scroll to zoom, drag to pan, click a dot to open that address. Positions come from which registry the address block was handed out in, so this is roughly right at the continent level and not precise city geolocation. It says so because that matters. Where a dot sits inside a region is arbitrary, not a location. Addresses on your own network are not shown here at all, because a private address is on somebody's network rather than in a country, and they are counted underneath instead.

What this is. traffic-analyzer is a tool I wrote and use. The same analysis runs as a Python command line program, and it agrees with this page packet for packet, which is a thing I test rather than assume. What it is not: it does not scan anyone, does not phone home, and does not upload your capture. It reads a file you already have.
